# Шесть методов класса Class для получения имени типа:

### Массивы

+ **getName()**: Возвращает внутреннее представление JVM. Например, для массива int[] это "[I", для массива строк "[Ljava.lang.String;".
+ **getCanonicalName()**: Возвращает null, если тип элемента массива не имеет канонического имени, иначе добавляет []. Пример: "java.lang.String[]".
+ **getSimpleName()**: Возвращает имя базового типа плюс []. Пример: "String[]".
+ **getTypeName()**: Возвращает полное имя базового типа плюс []

### Обобщенные типы

+ **getName(), getCanonicalName(), getSimpleName()**: Обобщенные типы сбрасывают параметры типа (удаление типов / type erasure). Например, для List<String> все три метода вернут "java.util.List" и "List" соответственно.
+ **getTypeName()**: Возвращает имя типа с сохраненными параметрами (например, "java.util.List<java.lang.String>").
+ **toGenericString()**: Возвращает расширенную строку, включающую модификаторы (например, public interface java.util.List<E>).

### Внутренние классы

+ **getName()**: Разделителем между внешним и внутренним классом выступает знак доллара \$. Пример: "com.example.Outer$Inner".
+ **getCanonicalName()**: Использует точку . вместо знака доллара. Пример: "com.example.Outer.Inner". Возвращает null для локальных или анонимных классов.
+ **getSimpleName()**: Возвращает имя только самого внутреннего класса. Пример: "Inner". Для анонимных классов возвращает пустую строку.
+ **getTypeName()**: Возвращает имя во внутреннем формате (как у getName), но с полным пакетом.

### Примитивные типы и void

+ **getName()**: Возвращает соответствующее ключевое слово Java (например, "int", "double", "void").
+ **getSimpleName()**: Похож на getName – возвращает ключевое слово типа.
+ **getCanonicalName()**: Возвращает null для примитивов.
+ **getTypeName()**: Возвращает ключевое слово типа (аналогично getName).
