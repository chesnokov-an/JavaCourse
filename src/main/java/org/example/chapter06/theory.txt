1) Ковариантность в java

- Ковариантностью называется сохранение иерархии наследования исходных типов в производных типах в том же порядке.

- Контравариантностью называется обращение иерархии исходных типов на противоположную в производных типах.

- Отсутствие наследования между производными типами называется инвариантностью.

1.1) Какие классы ковариантны в java по умолчанию?

- Массивы.

Если класс Sub является подклассом Super, то массив Sub[] является подтипом Super[].
Например, код
    String[] strArray = new String[5];
    Object[] objArray = strArray;
абсолютно легален с точки зрения компилятора.

2) PECS - Producer Extends, Consumer Super

- ? extends T - Producer - источник данных. Только читаем.
- ? super T - Consumer - приёмник данных. Только пишем.

3) Ограничения generics

+ 1. Нельзя использовать примитивы как параметры типа.
  2. Нельзя использовать instanceof с параметризованным типом <- Во время компиляции все типы оказываются базовыми
  3. Нельзя получить экземпляры обобщенных типов (нельзя new(T))
        массив потерял бы реальный тип
  4. Нельзя построить массивы параметризированных типов
        После стирания типов конструктор массива создаст массив базового типа E n t r y .
        И тогда станет возможным ввести объекты типа E n t r y любого типа (например, E n t r y < E m p lo y e e , M a n a g e r> )
+ 5. Нельзя употреблять параметры типа класса в статическом контексте
        стирание типов означает, что в стираемом классе с двумя параметрами типа имеется лишь одна такая переменная или метод,
        а не по одному из них для каждого параметра типа
+ 6. Методы не должны конфликтовать после стирания
+ 7. Объекты обобщенного класса нельзя генерировать или перехватывать.
  8. Нельзя создавать обобщенные классы, наследующие Throwable.
